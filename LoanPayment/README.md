# LoanPayment

## Description
This program takes the principal, interest rate, and number of years on a loan
and gives the user the monthly payment, the total of the payments over the years, 
and the total interest paid over the given time period. It then prints an 
amortization table breaking down how each monthly payment is divided into paying
the interest and principal.
