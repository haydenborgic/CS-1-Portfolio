# Play Pig Multiplayer

## Description
This program is the game "Play Pig" but it has a multiplayer function. It will ask the user how many people want to play and their names. It then begins cycling through each player's turn.
The player will roll 2 dice. If they get two 6s they will be awarded 24 points. If they roll two 1s they will lose. Otherwise they receive the total of the dice. The goal is to reach over 100.
If the player decides to enter "STOP" they automatically lose and the next player's turn begins. The winner is whoever can reach 100 in the fewest amount of rolls. If every player loses the program
prints that everyone loses. If a player wins, the players name is printed. If there is a tie the program will call out the name of each individual winner.
